# بازی هجوم — پروژه‌ی آماده‌ی اندروید

## راهنمای استفاده

1. یک ریپازیتوری جدید و **خالی** در گیت‌هاب بساز.
2. تمام محتوای همین زیپ (همون فایل‌ها و پوشه‌ها، بدون پوشه‌ی اضافه‌ی بیرونی) رو داخل اون ریپو آپلود کن.
   - می‌تونی مستقیم از صفحه‌ی گیت‌هاب گزینه‌ی "Add file → Upload files" رو بزنی و همه‌ی فایل‌ها/پوشه‌ها رو بکشی و رها کنی.
3. بعد از آپلود (commit روی branch اصلی)، برو به تب **Actions** توی ریپو.
4. ورک‌فلوی «Build Signed APK» به‌صورت خودکار اجرا میشه (چون روی هر push فعال شده). اگه اجرا نشد، دستی از همون تب Actions روی «Run workflow» بزن.
5. صبر کن (حدود ۳ تا ۶ دقیقه) تا بیلد سبز بشه.
6. روی اجرای موفق (run) کلیک کن، پایین صفحه بخش **Artifacts** رو باز کن و فایل `hojoom-signed-apk` رو دانلود کن. داخلش APK امضاشده‌ی نهاییته، آماده‌ی نصب یا آپلود توی کافه‌بازار.

## چیزی که داخل این پروژه انجام شده

- بازی (`index.html`) عیناً همون فایلیه که فرستادی، فقط دو تا هوک کوچیک اضافه شده که بعد از پایان هر مرحله یا گیم‌اور، تبلیغ اینترستیشیال رو صدا بزنه.
- فرکانس تبلیغ: هر ۳ رویداد (اتمام مرحله/باخت) یک‌بار، با حداقل ۲ دقیقه فاصله بین دو تبلیغ — هم سمت جاوااسکریپت بازی و هم سمت کد اندروید این محدودیت اعمال شده تا نه زیاد بشه نه کم.
- کلید اپ تپسل و شناسه‌ی زون اینترستیشیالی که فرستادی مستقیم توی `MainActivity.java` قرار گرفته.
- اپ به‌صورت کامل تمام‌صفحه (فول‌اسکرین، بدون نوار وضعیت و نویگیشن) اجرا میشه.
- آیکونی که فرستادی عیناً به‌عنوان آیکون اپ ثبت شده (فقط همون یک فایل، بدون آیکون اضافه).
- یک کیستور امضا (`app/keystore/release.keystore`) از قبل ساخته شده و توی `build.gradle` وصل شده، پس گیت‌هاب اکشن بدون هیچ تنظیم دستی یا سکرتی، مستقیم یک APK **امضاشده** تحویل میده.

## نکته‌ی مهم درباره‌ی امضا

این کیستور فقط برای این پروژه ساخته شده. اگه بعداً خواستی نسخه‌ی جدیدی از بازی رو منتشر کنی (آپدیت)، باید حتماً با همین کیستور امضا بشه وگرنه کافه‌بازار/گوگل‌پلی آپدیت رو قبول نمی‌کنن. پس این ریپو (یا حداقل فایل `app/keystore/release.keystore`) رو جایی امن نگه دار.
